# LuckySpinAPI

Учебный проект по МДК.03.02 «Управление проектами»: веб-API слот-игры на **C# / ASP.NET Core**. Игра идёт на виртуальные кредиты, реальные деньги и платежи в проекте не используются.

## Назначение

Игрок получает стартовый баланс, делает ставки и видит результат вращения трёх барабанов. Оператор (в планах) следит за игроками и может блокировать нарушителей.

## Целевые пользователи

| Роль | Что делает |
|------|-----------|
| Игрок | Смотрит баланс, делает ставки, смотрит историю игр |
| Оператор | Смотрит список игроков, блокирует и разблокирует игроков |

## MVP

- Просмотр баланса игрока (`GET /api/slots/balance/{userId}`)
- Ставка и вращение (`POST /api/slots/spin`)
- Начисление выигрыша: три одинаковых символа, выигрыш ×5
- Проверка ставки: ноль, отрицательное значение и ставка выше баланса отклоняются

Не входит в MVP: пополнение и вывод реальных денег, регистрация с паролями и JWT, мобильное приложение, внешняя база данных. Подробности в [паспорте проекта](docs/PROJECT_CHARTER.md).

## Критерии готовности MVP

1. API запускается командой `dotnet run`
2. Реализованы четыре функции MVP
3. Не менее 5 автоматических тестов проходят (`dotnet test`)
4. Отрицательная ставка не меняет баланс
5. README описывает запуск и правила игры

## Быстрый старт

Требуется [.NET 10 SDK](https://dotnet.microsoft.com/download) (поддерживаемая LTS-версия; проект переведён с .NET Core 3.1).

```bash
dotnet run --project LuckySpinAPI    # запуск, страница игры: https://localhost:5001
dotnet test                          # автоматические тесты (xUnit)
```

В Visual Studio откройте `LuckySpinAPI.sln` (нужна Visual Studio 2022 версии 17.14 или новее для .NET 10).

## API

| Метод | Адрес | Описание |
|-------|-------|----------|
| GET | `/api/slots/balance/{userId}` | Баланс. Единственный метод, который создаёт игрока: для нового `userId` создаётся запись со стартовым балансом 1000 |
| POST | `/api/slots/spin` | Тело `{"userId": 1, "betAmount": 100}`. Ответ 200: `combination`, `newBalance`, `isWin`, `winAmount` |

Ошибки всегда приходят в JSON `{"message": "..."}` на русском языке:

| Код | Когда |
|-----|-------|
| 400 | Ставка `<= 0` или больше баланса; баланс при этом не меняется |
| 404 | `spin` для несуществующего игрока (`spin` игрока не создаёт) |

Правила игры: символы 🍒, 🍋, 777; три одинаковых символа дают выигрыш ставка × 5. Правила определены в одном месте, `Services/SlotEngine.cs`. База данных работает в памяти (InMemory) и очищается при перезапуске.
